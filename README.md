# 弹珠防线 · RICOCHET BASTION

**塔防 × 弹珠台 × 肉鸽构筑。** 塔既是自动射击的防御设施，也是弹珠碰撞的机关。用挡板把球接回去，借塔之间的反弹打出元素联动，让整座防线变成一台连锁机器。

**[在线游玩](https://yexiaotingonemt-jpg.github.io/emberwatch/)** · [下载离线单文件](https://yexiaotingonemt-jpg.github.io/emberwatch/pinball-offline.html)

电脑与手机浏览器均可游玩，无需账号。离线版位于 `release/弹珠防线.html`，下载后用 Chrome / Edge 双击打开即可。

## 第一局怎么玩

开局已有火、冰两座塔与 220 金币。点击「迎战第 1 波」或按空格，观察第一球如何在两座塔之间触发蒸汽爆破。随后移动鼠标、手指，或按 A / D 控制挡板，把落下的弹珠重新打回去。

球撞在挡板中央时更接近竖直反弹；撞在边缘时斜向弹出。接球瞬间移动挡板会给球增加横向速度，可以主动改变下一次反弹路线。Q / E 调整下一球的发射方向，虚线会预览墙壁与塔的反弹。物理以每秒 180 次固定步长计算，并限制近水平轨迹，保持连续接球的节奏。

塔会自动射击，但亲手撞塔才能高效蓄能：每座塔满 3 格释放脉冲，撞击和脉冲还会向相邻塔传导能量。连线连接逻辑距离不超过 335 的塔；弹珠在元素仍有效时连续撞击相连的异元素塔，便会触发组合效果。

| 塔 | 建造费用 | 碰撞与联动 |
| --- | ---: | --- |
| 熔火撞针 | 90 | 给弹珠附火，燃烧敌人；满能释放范围爆破 |
| 霜晶棱柱 | 90 | 给弹珠附冰，减速敌人；满能冻结周围敌人 |
| 雷霆线圈 | 130 | 给弹珠附雷，造成连锁伤害；满能释放雷暴 |
| 分光核心 | 150 | 复制继承元素的真实弹珠，最多同时 5 颗；分裂球默认持续 10 秒 |

火 + 冰触发**蒸汽爆破**，冰 + 雷触发**冰导连锁**（界面亦称冰链传导），火 + 雷触发**等离子链**（界面亦称等离子弧）。同元素接力提高弹珠威力，分光核心则用于多球与能量中继。点击已建塔可查看充能、升级至三级或拆除回收部分金币。

一局共 12 波，第 4、8、12 波有首领，第 3、6、9 波结束后从随机三项改装中选择一项。碰撞和击杀积累过载，达到 100% 后按 F，获得持续 8 秒的加宽挡板、撞击强化与加速充能。球全部落空扣 1 点核心耐久，可重新发射；敌人到达底部也会扣耐久，核心归零即失败。

## 操作

| 操作 | 按键 / 方式 |
| --- | --- |
| 移动挡板 | 战场内移动鼠标 / 手指，或 `←` / `→`、`A` / `D` |
| 开始下一波 / 发射弹珠 | `Space`、主按钮；待发射时也可点击空白战场 |
| 调整下一球角度 | `Q` / `E`、角度按钮或战场内滚轮 |
| 选择建造塔型 | `1`–`4` 或塔卡，然后点击空塔基 |
| 查看塔、升级 / 拆除 | 点击已建塔，再用工坊按钮 |
| 核心过载 | `F` 或过载按钮，需蓄满能量 |
| 暂停 / 继续 | `P` 或暂停按钮 |
| 取消建造 / 选择，关闭说明 | `Escape` |

说明窗口会暂停进行中的战斗，关闭后恢复。声音在首次操作后启用，可通过右上角开关静音；全部音效由 Web Audio 实时合成。最高得分每秒、结算与重新开局时写入本机浏览器；清除站点数据会删除记录，当前一局进度不跨刷新保留。

## 开发与验证

需要 Node.js 20.19+ 或 22.12+，以及 npm。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。安装依赖后也可双击 `启动游戏.cmd`。

```powershell
npm test                 # 规则测试：23 项弹珠规则 + 15 项旧版回归
npm run build            # TypeScript 检查、Vite 构建、离线单文件打包
npm run preview          # 预览 dist/
npm run dev -- --port 4173
```

保留 4173 端口开发服务，在另一终端执行以下检查；浏览器脚本需要本机安装 Chrome：

```powershell
npm run test:browser     # 实际鼠标、键盘、触摸与界面回归
node qa/offline.mjs      # 断网 file:// 成品检查
npx tsx qa/pinball-balance.ts  # 15 组战役策略模拟
```

TypeScript、Phaser 3 与 Vite。当前入口为 `src/main.ts`，弹珠规则、画面、界面、声音位于 `src/pinball/`；旧版规则和测试保留作参考。开发模式暴露的 `window.__pinball` 调试入口在生产构建中移除。验证范围和模拟限制见 `qa/弹珠防线验收记录.md`。

## 发布

GitHub Pages 使用 `.github/workflows/pages.yml`，推送至 `codex/initial-release` 后自动安装锁定依赖、运行规则测试、构建并部署；拉取请求执行构建与测试。浏览器交互和离线验收脚本在本机执行。

相对资源路径兼容 GitHub Pages 仓库子目录。构建同时生成 `release/弹珠防线.html` 与网站上的 `pinball-offline.html`，其中脚本、样式和素材均已内嵌，无需联网运行。
