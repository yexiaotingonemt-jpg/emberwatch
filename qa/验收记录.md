# 余烬守望 · 验收记录

日期：2026-10-23。当前交付：`release/余烬守望.html`，所有代码、画面与音效均已内嵌，可使用 Chrome / Edge 离线打开。

## 已验证

- `npm run build`：TypeScript 严格检查、Vite 构建、离线单文件打包通过。
- `npm test`：15 项规则测试通过，覆盖金币、占用地基、升级分支锁定、护甲与法术、控制和连锁、暂停和速度、陨星冷却与边界、祝福、胜败与星级。
- `npm run test:browser`：通过真实鼠标和键盘操作测试建造、塔身选择、金币不足反馈、升级出售、开波、暂停恢复、说明弹窗、陨星及右键取消、地图切换、祝福、结算和本地记录。无页面运行错误。
- `node qa/offline.mjs`：断网状态从 `file://` 启动成品，实际验证建造、开波、说明与切换地图；无网络请求、无页面错误，测试入口已从成品移除。
- 桌面 1440×1000、小屏电脑 1280×720、移动 390×844 截图检查；电脑可同时看到战场和操作按钮，移动端无横向溢出。
- `npx tsx qa/balance.ts`：12 组完整 15 波战役全部可通关。实际统计见 `balance-results.json`。八座混合塔在灰烬山隘漏过一名领主，剩余 12 生命；更充分的阵容可满血通关。

## 交付说明

- 三张地图、四塔各三等级两条分支、六种敌人、15 波进攻、两次祝福选择、陨星技能、三档速度、程序音效与本地最佳星级。
- 当前是休闲塔防难度。完整一局无需联网；战绩保存在当前浏览器，浏览器禁止或清除本地存储会影响纪录保留。
- 构建会提示引擎单文件体积超过 500 kB；这是为离线单文件交付保留完整 Phaser 引擎，最终 HTML 约 1.3 MB。
