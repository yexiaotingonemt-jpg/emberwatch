# 弹珠防线 v2 · 验收记录

日期：2026-10-23。成品入口：`release/弹珠防线.html`，线上入口维持 `https://yexiaotingonemt-jpg.github.io/emberwatch/`，网站离线文件为 `pinball-offline.html`。

## 交付范围

- 弹珠 × 塔防 × 肉鸽改装：12 波、4 类塔、3 种异元素联动、3 次三选一改装，以及第 4、8、12 波首领。
- 每秒 180 次物理步进，挡板落点控制反弹角度，挡板移动传递横向速度；含墙壁反弹、塔体碰撞、轨迹预览、撞击停顿、拖尾、合成音效和近水平轨迹修正。
- 撞塔蓄能、相邻塔充能传导、满能脉冲、元素接力与真实多球分裂，上限 5 颗弹珠；过载满 100% 可开启 8 秒强化。
- 鼠标、键盘、触摸输入；暂停、说明、升级、拆除、重新开局、胜败结算与本机最高得分保存。

## 验证项目

- `npm test`：38 项规则测试通过，包括 23 项弹珠规则与 15 项旧版回归；旧版测试不计为新增弹珠玩法覆盖。
- `npm run build`：TypeScript 检查、Vite 构建与离线单文件打包。生产版不暴露 `window.__pinball`。
- `npm run test:browser`：真实首发球触发联动，鼠标 / 键盘 / 触摸挡板，建造、升级、拆除、金币不足反馈、暂停、说明、过载、补发球、改装选择、胜败、重新开局、最高分持久化与桌面 / 小屏电脑 / 手机布局。
- `node qa/offline.mjs`：Chrome 断网模式，直接通过 `file://` 启动 `release/弹珠防线.html`。检查无调试入口、初始 220 金币、默认首发球、开波、暂停 / 恢复、说明关闭、重新开局、在 (310,390) 建雷塔后恰剩 90 金币，以及 390×844 无横向溢出。要求无 HTTP 请求、无页面运行错误。截图为 `pinball-offline-serve.png`、`pinball-offline-desktop.png`、`pinball-offline-mobile.png`。离线版不读取内部游戏对象；默认首发球的融合次数断言由开发模式浏览器回归覆盖。
- `npx tsx qa/pinball-balance.ts`：15 组策略 / 种子模拟，结果见 `pinball-balance-results.json`。混合、元素、火塔为主三种主动策略各 3 组，共 9 组完成全部 12 波，剩余 19–20 点耐久；只靠被动射击的 3 组在第 5 波失败，固定挡板的 3 组在第 3 波失败。混合流派峰值达到 5 颗球，产生 46–60 次元素融合。

浏览器测试用真实操作覆盖首发球与常规交互，同时使用开发模式状态设置展示改装、超载和胜败界面；不把这些界面夹具算作自然完整通关。完整战役模拟使用游戏规则与合法资源开支，挡板由脚本自动跟球，因此模拟结果用于验证流程可完成与主动反弹的必要性，不代表普通玩家通关率。反弹主观手感仍以实际游玩为准。

## 运行说明

音效首次交互后启用，可能被浏览器自动播放策略暂时阻止。纪录保存在当前浏览器本地；禁止或清除存储时无法保证保留。最高分按每秒、胜败和重新开局保存，当前战役不跨刷新恢复。离线版已内嵌运行素材；首次开发依赖安装需要网络。

GitHub Pages 工作流负责规则测试、构建和发布；本地浏览器与离线检查不会自动在工作流执行。最终线上验收应以部署完成后的公开页面为准。
